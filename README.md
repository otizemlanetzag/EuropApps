# EuropApps

EuropApps is an AI app creator powered by Mistral AI.

## Features
- Describe an app in natural language.
- Generate a practical web-app starter.
- View generated files.
- Download generated files.
- Keep the Mistral API key server-side.

## Setup
1. Install Node.js.
2. Copy .env.example to .env.
3. Put your Mistral API key in MISTRAL_API_KEY.
4. Run npm install.
5. Run npm start.
6. Open http://localhost:3000

Never commit .env. It is ignored by .gitignore.
